# SniffCat

Privacy-focused IP abuse database and OSINT threat-intelligence platform for reporting and checking malicious IPs in real-time. Positioned as an AbuseIPDB-style community IP reputation service with a free, versioned REST API.

## APIs

- **SniffCat REST API** — Documented, versioned REST API (/api/v1/*) for checking IPs, retrieving blacklist feeds and report history, and submitting abuse reports. Uses X-Secret-Token header authentication with role-based rate limits. (`https://api.sniffcat.com`)
